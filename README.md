A program to help manage buff timers for Neverwinter Nights. 

So you don't run out of your precious spells mid-fight or go charging at a boss with 30 seconds left.

Comes with defaults that can be changed and saved.

Supports different profiles so you can set up one for each character with their own timer values as well as notification sounds for each timer, including adding custom ones if desired.

By default, the countdown timer starts blinking when there are 2 Rounds/Turns/Hours left of the countdown and no alarm sound is played. This can be changed in the customize window and is saved to the current profile when you hit "ok" to exit. Default profile can be edited and changed to preference, the program only creates a default.json if none are present.
